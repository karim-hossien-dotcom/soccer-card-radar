## Decisions (2026-10-16)
1. Bid execution: app decides, Gixen executes via its API (C3c); assisted snipe alert (C3b) as fallback; Offer API application in parallel. Approved 2026-10-16.
2. Data: free stack (PSA Public API + manual Card Ladder entry); no scheduled Card Ladder pulls (ToS). Approved 2026-10-16.
3. 2014 Prizm WC Ronaldo Silver #161 = BGS 9 (confirmed).
4. Write routes are guarded by ADMIN_TOKEN (no login; public Render URL). Approved with A4 2026-10-16.
6. Snipe score (C1, Karim 2026-10-16): card-led 65/35 (grading upside 25, steal 25, rarity 15; signal 12, tier 8, form 15). Real-life form counts for young / in-form players only after Karim approves the researcher's numbers; legends (Ronaldo, Messi, Salah, Neymar, Lewandowski) ignore stats. Gem rates come from the PSA population report (eBay has no grade data; Marketplace Insights is sold prices and restricted), scaled for raw-buy selection (PSA 10 x0.6, PSA 9 x0.5, rest at raw) and by comp confidence (High 1 / Medium 0.85 / Low 0.6).
5. Visual redesign: "Matchday programme" direction (pitch #0E3B2E, chalk #F4F1EA, gold #D4A017 sparingly; Archivo + Source Serif 4; team-sheet tables; full-bleed photos). Order: ship A4 first, then UI-1 across the whole app. Chosen by Karim 2026-10-16.
